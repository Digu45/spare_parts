    Backup & Restore

    Bills are always kept in this browser on this computer. When online backup is on (sign in at the top right), every new bill is also saved online automatically, so nothing is lost if the browser is cleared or the computer is lost. A backup file is an extra copy you can restore from.

    The file goes to this computer's Downloads folder, named with the date and time, so files add up: keep the newest and delete old ones now and then. In Chrome or Edge keep "Ask where to save each file" switched off in the download settings, otherwise a window pops up every time.
